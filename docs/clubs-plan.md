# Daamal.org — КЛУБЫН СИСТЕМ: бүрэн төлөвлөгөө

> Зорилго: багш, сургууль, чөлөөт дасгалжуулагч өөрийн **клуб** үүсгэж,
> сурагчдаа нэг дор хөтөлж, клубын дотоод тэмцээн зохион байгуулж,
> клубууд хоорондоо өрсөлдөх.
>
> Одоогийн байдал: `/tournament → Клубууд` таб нь ЗӨВХӨН танилцуулга
> (`ClubsTab`, хуурамч өгөгдөлгүй). Хүснэгт, API, урсгал бүгд БАЙХГҮЙ.

---

## 0. ГОЛ ШИЙДВЭРҮҮД (эхлээд эдгээрийг батлах)

| № | Асуулт | Санал | Шалтгаан |
|---|--------|-------|----------|
| 0.1 | Хэн клуб үүсгэх вэ? | **Багш эрхтэй хүн** (`role`/`secondaryRole` = teacher) ба админ | Клубт хүүхдийн өгөгдөл урсана. Сурагч өөрөө клуб үүсгэвэл «клуб» гэдэг үг найзын групп болж хувирна |
| 0.2 | Нэг хүн хэдэн клубын эзэн байх вэ? | **1** (админ л илүүг зөвшөөрнө) | Хоёр клубтай багш нь хоёрын хооронд сурагч шилжүүлж чансаа/шагнал хөөрөгдөх зам |
| 0.3 | Сурагч хэдэн клубт байх вэ? | **1 клуб** | «Миний клуб» гэдэг нь хамаарлын мэдрэмж. Хоёр клубт байвал клубын тэмцээн, чансаа хоёуланд тоологдож давхардал үүснэ |
| 0.4 | Клуб нээлттэй үү, батлалттай уу? | **Батлалттай** (`join_policy`: `code` \| `request` \| `closed`) | Хүүхдийн бүлэгт хэн ч орох боломжтой байх нь аюулгүй байдлын эрсдэл |
| 0.5 | Клубын чансаа? | Гишүүдийн **дээд 5-ын дундаж**, хамгийн багадаа 5 чансаатай гишүүнтэй үед | Зүгээр дундаж нь «шинэ гишүүн авбал клуб унана» гэсэн хорт хөшүүрэг болно (багш шинэ хүүхэд авахаас цээрлэнэ) |
| 0.6 | Төлбөр? | Клуб **үнэгүй**, 30 гишүүнээс дээш бол Premium/сургуулийн гэрээ | Багшийг эхнээс хориглох нь системийг хоосон болгоно |
| 0.7 | Эцэг эхийн зөвшөөрөл? | Клубт нэгдэхэд **эцэг эх холбоотой бол мэдэгдэл** явна | Хүүхэд өөрөө шийднэ, гэхдээ эцэг эх мэдэх ёстой |

## 1. КЛУБ ҮҮСГЭХ УРСГАЛ

```
Багш → /clubs/new
  1. Нэр (2–40 тэмдэгт, давхардал шалгана)
  2. Товч танилцуулга (≤300)
  3. Таних тэмдэг: өнгө + дүрс (лого нь ХОЖИМ, Firebase Storage)
  4. Хаяг/сургууль (сонгомол), хот/дүүрэг
  5. Тоглоом: шатар / даам / хоёулаа
  6. Нэгдэх дүрэм: код | хүсэлт | хаалттай
  → «Клуб үүсгэх»
```

**Сервер тал** (`POST /api/clubs`):

1. `requireTeacher` — багш эсэхийг шалгана.
2. Аль хэдийн эзэн болсон клубтай эсэхийг шалгана (0.2).
3. Нэрийг `lower(trim())`-ээр давхардал шалгана (UNIQUE индекс).
4. `clubs` мөр + эзний `club_members` мөр (`role = 'owner'`) — **нэг
   гүйлгээнд**. Эс бөгөөс эзэнгүй клуб үүсч, хэн ч удирдах аргагүй болно.
5. Нэгдэх код: 6 тэмдэгт (`studentInviteCode`-ийн цагаан толгойгоор,
   төөрөгдүүлэх `0/O/1/I` байхгүй).

**⚠ Зориуд ХИЙХГҮЙ зүйлс**: клуб үүсгэхэд төлбөр, админы батламж,
баталгаажуулах и-мэйл. Гурвуулаа нь багшийг хаалганаас буцаана — хяналт
нь ГОМДОЛ (`report`) ба админы устгах эрхээр хийгдэнэ.

## 2. ГИШҮҮНЧЛЭЛ

### 2.1 Нэгдэх гурван зам

| Зам | Хэн үйлдэх | Урсгал |
|-----|-----------|--------|
| **Код** | Сурагч | «Клубын код» оруулна → шууд гишүүн |
| **Хүсэлт** | Сурагч | Хүсэлт явна → багш батална (`club_requests`) |
| **Урилга** | Багш | Аль хэдийн холбоотой сурагчаа (`student_links`) шууд нэмнэ |

**⚠ Rate limit ЗААВАЛ**: клубын код нь хүүхдийн бүлэг рүү нээгддэг
хаалга. `students` route-той ижил зарчим — кодыг таах оролдлогыг тоо
ширхгээр хаана.

### 2.2 Үүргүүд (`club_members.role`)

- `owner` — үүсгэсэн багш. Клубыг устгах, эзэн шилжүүлэх.
- `coach` — хамтран хөтлөгч багш. Гишүүн батлах, тэмцээн үүсгэх.
- `member` — сурагч.

### 2.3 Гарах / хасах

- Сурагч **хэзээ ч** өөрөө гарна (батламж шаардахгүй — хүүхдийг бүлэгт
  хорих нь болохгүй).
- Багш гишүүнийг хасна; шалтгааныг бичнэ (лог).
- Эзэн клубыг устгахад гишүүд **чансаагаа хадгална** (чансаа нь хувь
  хүний, клубын БИШ), клубын тэмцээний түүх нь `club_id = null` болно.

## 3. КЛУБЫН ТЭМЦЭЭН

Тэмцээний сервер дээр `access` талбар аль хэдийн байна
(`open | members | mind | mind-members`). Нэмнэ:

- `access = 'club'` + `club_id` — зөвхөн тэр клубын гишүүд.
- Батламжийг tactiq тал шалгана (`lib/api/tournamentAccess.ts`-д
  `club` тохиолдол нэмэгдэнэ: `club_members` дээр мөр байгаа эсэх).
- Клубын тэмцээн нь **чансаа тогтоож БОЛНО** (`rated`) — гэхдээ
  анхдагчаар үгүй. Жижиг хаалттай бүлэгт хоёр хүн тохиролцох нь
  хамаагүй хялбар тул зөвхөн 8+ оролцогчтой үед `rated` зөвшөөрнө.

**Клуб хоорондын тэмцээн** (2-р шат): `format = 'team'` аль хэдийн байна.
Клуб бүрээс 4 тоглогч, нийлбэр оноогоор эрэмбэлнэ.

## 4. КЛУБЫН ЧАНСАА

```
club_rating = дээд 5 гишүүний чансааны дундаж
  (зөвхөн provisional БИШ гишүүд, 10+ тоглолт)
  5 хүрэхгүй бол «чансаа тогтоогүй»
```

**⚠ Яагаад дээд 5 вэ**: бүтэн дундаж нь багшийг шинэ хүүхэд авахаас
цээрлүүлнэ («шинэ гишүүн клубыг унагана»). Дээд 5 нь клубын ХҮЧИЙГ
хэмжих ба шинэ гишүүн ХЭЗЭЭ Ч хортой биш.

**⚠ Гишүүний тоо ТУСАД НЬ харагдана** — «40 гишүүн» гэдэг нь өөрөө
ололт, гэхдээ чансаанд нөлөөлөхгүй.

Тооцоолол: шөнийн cron (`/api/cron/club-ratings`) — гишүүн бүрийн
чансааг унших нь хүнд тул 15 минут тутам БИШ, өдөрт нэг удаа.

## 5. САНГИЙН ЗОХИОМЖ

```sql
-- drizzle/0051_clubs.sql
CREATE TABLE clubs (
  id            uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  name          varchar(40)  NOT NULL,
  /* Давхардал шалгах түлхүүр — жижиг үсгээр. */
  name_key      varchar(40)  NOT NULL,
  description   varchar(300) NOT NULL DEFAULT '',
  owner_uid     varchar(128) NOT NULL,
  /* "chess" | "checkers" | "both" */
  games         varchar(16)  NOT NULL DEFAULT 'both',
  /* Таних тэмдэг — лого ХОЖИМ. Tailwind-ийн бүтэн класс мөр БИШ,
     кодоор буулгадаг товч түлхүүр ("indigo", "amber", …). */
  color         varchar(16)  NOT NULL DEFAULT 'indigo',
  icon          varchar(16)  NOT NULL DEFAULT 'shield',
  school_slug   varchar(16),
  city          varchar(40),
  /* "code" | "request" | "closed" */
  join_policy   varchar(16)  NOT NULL DEFAULT 'code',
  join_code     varchar(8)   NOT NULL,
  /* Cron-оор бөглөгдөнө (§4). NULL = тогтоогүй. */
  rating        integer,
  member_count  integer      NOT NULL DEFAULT 0,
  status        varchar(16)  NOT NULL DEFAULT 'active', -- active | blocked
  created_at    timestamptz  NOT NULL DEFAULT now(),
  updated_at    timestamptz  NOT NULL DEFAULT now()
);
CREATE UNIQUE INDEX clubs_name_uq ON clubs (name_key);
CREATE UNIQUE INDEX clubs_code_uq ON clubs (join_code);
CREATE UNIQUE INDEX clubs_owner_uq ON clubs (owner_uid) WHERE status = 'active';

CREATE TABLE club_members (
  id         uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  club_id    uuid NOT NULL REFERENCES clubs(id) ON DELETE CASCADE,
  uid        varchar(128) NOT NULL,
  /* owner | coach | member */
  role       varchar(16)  NOT NULL DEFAULT 'member',
  joined_at  timestamptz  NOT NULL DEFAULT now()
);
/* ⚠ НЭГ ХҮН НЭГ КЛУБТ (0.3) — тиймээс түлхүүр нь `uid`, (club_id, uid) БИШ. */
CREATE UNIQUE INDEX club_members_uid_uq ON club_members (uid);
CREATE INDEX club_members_club_idx ON club_members (club_id, role);

CREATE TABLE club_requests (
  id         uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  club_id    uuid NOT NULL REFERENCES clubs(id) ON DELETE CASCADE,
  uid        varchar(128) NOT NULL,
  message    varchar(200) NOT NULL DEFAULT '',
  /* pending | accepted | declined */
  status     varchar(16)  NOT NULL DEFAULT 'pending',
  created_at timestamptz  NOT NULL DEFAULT now()
);
CREATE UNIQUE INDEX club_requests_uq ON club_requests (club_id, uid)
  WHERE status = 'pending';
```

**⚠ `member_count` нь ДАВХАРДСАН тоо** (`club_members`-ээс тоолж ч
болно): жагсаалт дээр 50 клуб харуулахад 50 `count(*)` явуулах нь
дэмий. Гишүүн нэмэх/хасах гүйлгээн ДОТОР шинэчилнэ.

**⚠ `clubs_owner_uq` нь ХЭСЭГЧИЛСЭН** (`WHERE status = 'active'`):
устгагдсан клуб нь багшийг шинэ клуб үүсгэхээс хориглох ёсгүй.

## 7. ХАРАГДАХ ХЭСЭГ

1. **`/tournament → Клубууд`** таб (одоогийн танилцуулгыг орлоно):
   - Миний клуб (эсвэл «Клубт нэгдэх» / багшид «Клуб үүсгэх»)
   - Клубуудын чансаа (дээд 20)
   - Хайлт + хот/тоглоомоор шүүлт
2. **`/clubs/[id]`** — клубын хуудас: тэмдэг, тайлбар, гишүүд, клубын
   тэмцээнүүд, нэгдэх товч.
3. **`/clubs/new`** — үүсгэх хэлбэр (багшид л).
4. **Багшийн хэсэг** (`/teacher`) — «Миний клуб» карт: хүсэлтүүд,
   гишүүд, клубын тэмцээн үүсгэх.
5. **Профайл** — клубын тэмдэг + нэр (гишүүн бол).

**⚠ ХАРАГДАЦЫН ЗАРЧИМ** (аль хэдийн хүчинтэй): шатар/даам ялгаа нь
өнгө + дүрс + БИЧВЭР гурвуулаараа (`lib/tactiq/gameTheme.ts`). Клубын
өнгө нь Tailwind-д **бүтэн класс мөрөөр** буулгагдана — `bg-${color}`
гэж үүсгэвэл CSS-д орохгүй.

## 8. ХҮҮХДИЙН АЮУЛГҮЙ БАЙДАЛ (зайлшгүй)

- Клубын нэр, тайлбар нь **нийтэд** харагдана → админ устгах эрхтэй,
  `status = 'blocked'`.
- Клуб дотор **чат БАЙХГҮЙ** (1-р шатанд). Хүүхдийн бүлэг чат нь
  модерацийн бүтэн систем шаардана — түүнгүйгээр нээх нь хариуцлагагүй.
- Гишүүдийн жагсаалтад **зөвхөн харагдах нэр, аватар, чансаа** — утас,
  и-мэйл ХЭЗЭЭ Ч үгүй (багшийн холбоо барих нь `coach_profiles`, тэр нь
  багшийн ӨӨРИЙН зөвшөөрөлтэй).
- Эцэг эх холбоотой бол нэгдэх/гарах үед **мэдэгдэл** (`push`).
- Гомдол мэдүүлэх товч (`club_reports`) — 2-р шат.

## 9. ХЭРЭГЖҮҮЛЭХ ДАРААЛАЛ

| Шат | Агуулга | Хэмжээ |
|-----|---------|--------|
| **1** | Миграци `0051`, схем, `POST/GET /api/clubs`, кодоор нэгдэх, `/clubs/[id]`, Клубууд табыг бодит болгох | ~2 өдөр |
| **2** | Хүсэлт + батлах, багшийн хэсгийн карт, гишүүн хасах/гарах, эцэг эхийн мэдэгдэл | ~1.5 өдөр |
| **3** | Клубын тэмцээн (`access = 'club'`, тэмцээний сервер дээр `club_id`) | ~2 өдөр |
| **4** | Клубын чансаа + cron + клубуудын жагсаалт | ~1 өдөр |
| **5** | Клуб хоорондын тэмцээн (`team`), гомдол, лого хуулах | ~2 өдөр |

**⚠ 1-р шат нь ӨӨРӨӨ БҮТЭН БҮТЭЭГДЭХҮҮН**: клуб үүсгэж, сурагч кодоор
нэгдэж, гишүүдээ харна. Тэмцээн, чансаа нь түүний ДЭЭР нэмэгдэнэ.

## 10. ХЯЗГААР ТОХИОЛДЛУУД

| Тохиолдол | Шийдэл |
|-----------|--------|
| Багш клубаа устгахад гишүүд | Клубгүй болно, чансаа хэвээр, тэмцээний түүх `club_id = null` |
| Эзэн багшийн эрх хасагдвал | Клуб `blocked` БИШ — админ шинэ эзэн тохооно (`coach` дотроос) |
| Хоёр клуб ижил нэртэй | `name_key` UNIQUE — «Энэ нэр аль хэдийн байна» |
| Код таах оролдлого | Rate limit + 6 тэмдэгт (32³²) + `status` шалгалт |
| Сурагч хоёр клубт | `club_members_uid_uq` — «Та аль хэдийн клубын гишүүн» |
| Клуб 5-аас бага чансаатай гишүүнтэй | «Чансаа тогтоогүй» (тоо харуулахгүй) |
| Клубын тэмцээнд 2 хүн | `rated` ХҮЧИНГҮЙ (8+ оролцогч шаардлага, §3) |
| Устгагдсан хаягийн гишүүнчлэл | `users`-тай INNER JOIN — жагсаалтаас өөрөө хаягдана |
